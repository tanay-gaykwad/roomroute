# Support

RoomRoute is an open-source prototype maintained as a portfolio project. There is no staffed customer-support or rental-broker service.

- For reproducible software bugs, use the repository's bug report form.
- For a proposed improvement, use the feature request form.
- For setup and contribution questions, read the README and CONTRIBUTING guide first.
- For a security vulnerability, follow the private reporting instructions in [SECURITY.md](SECURITY.md). Do not post exploit details in a public issue.
- For questions about a real rental, contact the property owner directly and independently verify the listing. RoomRoute does not currently provide verified live rental inventory.

There is no response-time guarantee. Please do not post personal contact details, exact home addresses, account credentials, or private messages in public issues.
